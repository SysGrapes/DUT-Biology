## 两个核心设计
**分点答案**：每道简答/论述/计算题拆成 3~6 个得分点，每点前面一个 4~10 字**红色记忆锚点**，后面跟展开。背锚点、答题按锚点铺开。

**关键词即点即查**：题干与答案里的术语带红色虚线下划线，点一下弹出定义；操作条可关掉。

## 数据来源（重要）
- 题目：1999—2025 年真题卷照片 82 页 + 既有题库 181 题，合并去重后 1043 题。
- 答案：**以两个复习资料包（27631 / 27880）里的《真题分类》答案解析为准**。这些 docx 是扫描件，已逐页 OCR（138 页、约 15 万字）建成答案库，与题库做题干匹配，命中 170 道（155 道按资料原文重写，15 道判定非同题保留教材口径）；358 条名词解释中 252 条定义改为资料原文。
- 未命中的题（多为资料未覆盖的 1999—2005、2023—2025 年）按教材通行口径撰写，题卡 note 里注明。
- 能量计算统一口径：NADH=2.5、FADH₂=1.5、GTP=1、脂肪酸活化耗 2、胞质 NADH 走 3-磷酸甘油穿梭。
