## 两个核心设计
**分点答案**：每道简答/论述/计算题拆成 3~6 个得分点，每点前面一个 4~10 字**红色记忆锚点**，后面跟展开。背锚点、答题按锚点铺开。

**关键词即点即查**：题干与答案里的术语带红色点线，点一下弹出定义；操作条可关掉。

**关键题带插图**：双倒数作图（竞争/非竞争/反竞争）、米氏曲线、氧解离曲线、凝胶过滤、肽平面、v–[E] 作图、SDS-PAGE、遗传密码表、2022 酶纯化表，共 11 幅，挂在 41 道相关题卡下（还原条件、无网络也能看）。

**物质名带结构式**：ATP、NADH、葡萄糖、软脂酸这类物质名带**青绿虚线下划线**，点一下直接弹出结构式与分子式（如 `?mol=atp` 可深链）。结构式不是手绘，是用标准 SMILES 经 RDKit 生成、并逐个用分子式校验过的，避免画错。

## 数据来源（重要）

### 权威答案册（本次新增）
- 《880 生物化学考研真题参考答案》83 页（2001—2005、2010—2017、2019—2025，共 294 条）与《631 分子生物学考研真题答案》80 页（2002—2025，共 205 条），逐页 OCR 转录 → 按年份+题干匹配题库 → 以册子原文为骨改写成带锚点的分点答案。
- 结果：269 道题（880 计 145、631 计 124）的答案已换成参考答案册口径，note 里标「口径：《…参考答案》印刷版 · 年份 · 小节」；原册明显的硬错（如把 CO 产物写成碳氧血红蛋白、dCas9 说成可切割双链）已更正并在 note 注明。
- 册子未覆盖的年份（880 无 1998—2000、2006—2009、2018；631 无 2009—2010、2012）仍按教材口径，请以此为准判断可信度。

- 题目：1999—2025 年真题卷照片 82 页 + 既有题库 181 题，合并去重后 1043 题。
- 答案：**以两个复习资料包（27631 / 27880）里的《真题分类》答案解析为准**。这些 docx 是扫描件，已逐页 OCR（138 页、约 15 万字）建成答案库，与题库做题干匹配，命中 170 道（155 道按资料原文重写，15 道判定非同题保留教材口径）；358 条名词解释中 252 条定义改为资料原文。
- 未命中的题（多为资料未覆盖的 1999—2005、2023—2025 年）按教材通行口径撰写，题卡 note 里注明。
- 能量计算统一口径：NADH=2.5、FADH₂=1.5、GTP=1、脂肪酸活化耗 2、胞质 NADH 走 3-磷酸甘油穿梭。

### 期末考试题（本次新增）
- 来源：`27631_molbio__期末题分类--{名词解释,填空选择,简答答题}` 三份扫描件 OCR 合并稿（大连理工本科试题），共 7 个场次：07年1月10日、08年1月09日 A/B 卷、10年1月8日 A/B 卷、11年7月25日、2011年春季期末试题。
- 拆出 **257 题**：名词解释 48、填空 56、选择 83、判断 20、简答 50。解析脚本见 `work/final_exam/build_final.py`，产物 `data/final_questions.json` → `final.js`。
- 原卷是「答案已填入」的复习稿，处理方式分三类：
  - **选择 / 判断**：答案字母或 X/V 从题干抹掉（换成「（　）」），答案与选项放在展开区，保证翻卡自测有效；多选题如「（A、C）」按两个选项分别给出。
  - **填空**：`q` 保留卷面原文、`q_masked` 把括号答案换成「（　）」，翻卡前隐藏、展开后还原卷面并给逐空答案分点。带评分标注（如「0.5 分」）或答案直接以空格写在题干里的，无法遮盖，已在 note 说明。
  - **配伍填空**（10年A卷 1—5 题，题干多个括号各填一个选项字母）：`q` 保留卷面字母、`q_masked` 隐藏，逐空给出「第 N 空：X. 选项文本」。
- 原卷写「略」的名词解释，用同套期末试卷里同名术语的完整定义回填；原卷写「（参考上述）」或漏印答案的简答题，按考点关键词在全部场次里找语义吻合的原题回填（来源场次不一定是本题场次，note 会点名来源）。未找到来源的（如 08年B卷「前导肽」）如实标注缺失，不编造。
- 简答题答案里的 markdown 表格会在题卡上渲染成 HTML 表格。

**独立复核**：已派子代理把 257 题逐题回看三份原文，报告 `work/final_exam/review_report.md`。
结论是题量、场次归属、83 道选择题答案字母、20 道判断题 V/X、名词解释「略」回填、配伍题判定全部无误；
另修掉 6 个确定性错误（嵌套括号/英文缩写被误当成填空答案、3 处选项文本被 OCR 里的孤立字母截断、
1 处简答题「参考上述」未回填）、5 处 note 措辞、4 处跨页断词、2 处题干小问错位与 2 处语义存疑的填空。
修正集中在 `work/final_exam/polish.py`（幂等、可复现），重建顺序固定为：
`build_final.py` → `polish.py` → `make_final_js.py`。

## URL 参数
`?d=pg|fn`（题库域，切换按钮会自动改写） · `?m=q|kp|tm|ss|ms|mn|stat` · `?s=631|880|all` · `?y=21` · `?t=简答` · `?st=3` · `?id=n0067` / `?d=fn&id=f0049` · `?r=1` · `?mol=atp` · `?q=米氏方程 抑制`（直接搜索）

期末题库下若深链带了 `m=kp` 或 `m=tm`，会自动回落到「期末速刷」。

## 全文搜索说明
- 索引在浏览器里即时构建（首次搜索约 20 ms 建完），不联网、不额外占文件体积。
- 多个词用空格／逗号分开＝同时包含（AND）；中文不切词，直接子串匹配，所以「转录 抑制」与「转录后抑制」都能命中。
- 排序按「命中字段权重＋年份数」：标题命中 > 答案正文 > 提示 > 章节名。
- 顶部科目分段（全部／631／880）会同时约束搜索范围。
- 名词卡与同名真题只保留真题那条，避免重复；名词仍可在「名词卡」页翻。
